# math-for-cs-101

`math-for-cs-101` 시리즈 예제 코드 저장소입니다.
각 에피소드는 작은 계산 예제를 통해 수학 개념을 코드로 확인하도록 구성했습니다.

## 요구사항

- Python 3.11+

## 설치

```bash
pip install -r requirements.txt
```

## 실행

```bash
python ko/01-why-math-for-cs/step01_complexity_demo.py
python en/10-algorithms-and-math/step01_algorithms_and_math.py
pytest -q
```
