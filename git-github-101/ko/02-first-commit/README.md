# Git & GitHub 101 (2/10): 첫 commit 만들기 - init, status, add, commit

Git Github 101 시리즈 2편 예제 코드입니다.

## 학습 목표

- `git init`은 현재 디렉터리에 정확히 무엇을 만들까요?
- `git status`는 파일 상태를 어떤 말로 보여 줄까요?
- `git add`는 단순히 "파일을 추가한다"는 뜻일까요, 아니면 더 정확한 의미가 있을까요?
