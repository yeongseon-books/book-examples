# discrete-math-101 예제 코드

Discrete Math 101 시리즈의 각 에피소드를 실행 가능한 순수 Python 코드와 테스트로 정리한 저장소입니다.

## 구성

- `ko/01-what-is-discrete-math.py`
- `ko/02-propositions-and-logic.py`
- `ko/03-sets-and-functions.py`
- `ko/04-relations-and-equivalence.py`
- `ko/05-proof-techniques.py`
- `ko/06-sequences-and-recurrence.py`
- `ko/07-combinatorics.py`
- `ko/08-graph-theory-basics.py`
- `ko/09-trees-and-graph-traversal.py`
- `ko/10-discrete-math-and-algorithms.py`
- `en/` 경로에 동일 예제(영문 주석)
- `tests/` 에피소드별 pytest

## 실행

```bash
python ko/02-propositions-and-logic.py
python en/08-graph-theory-basics.py
```

## 테스트

```bash
python -m pytest -q
```
