# AI Data Preparation 101 (1/10): 데이터 준비가 모델 품질을 결정하는 이유

- 모델 아키텍처보다 데이터 준비가 더 큰 차이를 만드는 순간은 언제일까요?
- 겉보기 정확도는 높은데 실제 사용자 경험이 나빠지는 대표적인 데이터 실패는 무엇일까요?
- 수집부터 분할까지의 데이터 준비 단계를 왜 하나의 파이프라인으로 봐야 할까요?
