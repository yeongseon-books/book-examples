# book-examples

영선북스 시리즈 예제 코드 모노레포. 모든 예제는 `ko/`·`en/` 양 언어로 제공되며 pytest로 검증됩니다.

## 빠른 시작

```bash
# 특정 시리즈 실행
cd ai-agent-101
pip install -r requirements.txt 2>/dev/null; pytest -q
```
