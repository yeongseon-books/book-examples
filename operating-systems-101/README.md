# operating-systems-101 예제 코드

운영체제 101 시리즈(1~10화)용 Python 예제 코드입니다.

- `ko/`: 한국어 파일명 예제
- `en/`: 영어 파일명 예제
- `tests/`: pytest 테스트

실행:

```bash
python -m pip install -r requirements.txt
pytest -q
```

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```
