# LangGraph 101 examples (English)

Every example in this folder uses English prompts, node outputs, and demo messages.

## Example list

1. `01_graph_basics.py` — StateGraph, basic nodes, and edges
2. `02_state_and_checkpoints.py` — MemorySaver checkpointer
3. `03_conditional_edges.py` — conditional routing and loop control
4. `04_tool_calling_agent.py` — tool-calling agent graph
5. `05_multi_agent.py` — supervisor-worker pattern
6. `06_langgraph_complete.py` — complete production-style agent
